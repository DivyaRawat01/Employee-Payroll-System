# Payroll Management System (Oracle PL/SQL)

A mini project in which the main component is **Oracle PL/SQL**. Employee, attendance and salary data are stored in an Oracle database, and monthly payroll is generated by stored functions, procedures, cursors and triggers. A basic Flask web front-end (HTML forms + CSS) lets you use it from the browser.

## Features
- Add employees with department and basic salary
- Record monthly attendance
- Generate payroll for all employees with one click (`sp_generate_payroll`)
- View the payroll report for any month, with total net payout
- Data validation through database triggers, with error messages shown on the page

## Tech stack
| Layer | Technology |
|---|---|
| Database | Oracle Database (Oracle FreeSQL), PL/SQL |
| Backend | Python 3.9+, Flask, python-oracledb (thin mode) |
| Front-end | HTML5, CSS3, Jinja2 templates |

`templates` and `static` must stay in the same folder as `app.py`.

## Database design
| Table | Purpose | Keys |
|---|---|---|
| Departments | Department list | PK dept_id |
| Employees | Employee details | PK emp_id, FK dept_id |
| Attendance | Working days and days present per month | PK att_id, FK emp_id, unique (emp_id, att_month) |
| Salary_Details | Basic salary, HRA %, DA %, PF % | PK/FK emp_id |
| Payroll | Generated monthly salary | PK payroll_id, FK emp_id, unique (emp_id, pay_month) |

## PL/SQL components
| Object | Type | What it does |
|---|---|---|
| `fn_gross_salary` | Function | Basic + HRA + DA |
| `fn_deductions` | Function | PF + pay cut for absent days |
| `sp_generate_payroll` | Procedure | Cursor loop over all employees, inserts into Payroll |
| `sp_payroll_report` | Procedure | Cursor-based formatted report (DBMS_OUTPUT) |
| `trg_validate_salary` | Trigger | Basic salary must be at least 10000, PF at most 20% |
| `trg_validate_attendance` | Trigger | Days present cannot exceed working days |

Exceptions handled: `NO_DATA_FOUND`, `DUP_VAL_ON_INDEX`, `OTHERS`, and custom errors with `RAISE_APPLICATION_ERROR`.

### Salary formula
```
Gross       = Basic + (Basic x HRA%) + (Basic x DA%)
Absent cut  = (Basic / Working days) x (Working days - Days present)
Deductions  = (Basic x PF%) + Absent cut
Net salary  = Gross - Deductions
```
Defaults: HRA 20%, DA 10%, PF 12%.

## Setup

### 1. Create the database objects
In your Oracle FreeSQL worksheet (or SQL Developer), logged in as your schema user:
1. Run `01_schema.sql`
2. Run `02_plsql.sql`

### 2. Install Python packages
```
pip install -r requirements.txt
```

### 3. Configure the connection
Open `app.py` and edit the block at the top:
```python
DB_USER = "your_schema_username"
DB_PASSWORD = "your_password"
DB_DSN = "tcps://db.freesql.com:2484/your_service_name"
WALLET_DIR = None          # FreeSQL needs no wallet
WALLET_PASSWORD = None
```
Other databases:
- Local Oracle XE: `DB_DSN = "localhost:1521/XEPDB1"`
- Oracle Cloud Autonomous Database: set `DB_DSN` to a service name from `tnsnames.ora`, and set `WALLET_DIR` and `WALLET_PASSWORD` for the downloaded wallet.

### 4. Run
```
python app.py
```
Open http://127.0.0.1:5000

## How to use
1. **Employee Details**: add or view employees.
2. **Salary Processing**: Step 1 saves attendance for an employee and month. Step 2 generates payroll for that month.
3. **Payroll Report**: choose the month and view the report.

The sample data has attendance only for **October 2026**, so use that month first. Employees with no attendance for a month are skipped, with a message on the page.

## Testing in SQL
```sql
SET SERVEROUTPUT ON
EXEC sp_generate_payroll(DATE '2026-10-01');
EXEC sp_payroll_report(DATE '2026-10-01');

-- Should fail with ORA-20010
UPDATE Salary_Details SET basic_salary = 5000 WHERE emp_id = 101;
```

## Troubleshooting
| Problem | Fix |
|---|---|
| `TemplateNotFound` | Keep the `templates` and `static` folders next to `app.py` (names must be exact). |
| `ORA-00942: table or view does not exist` | Run `01_schema.sql` and `02_plsql.sql` first, in the same schema the app connects to. |
| `ORA-01017: invalid username/password` | Check `DB_USER` and `DB_PASSWORD` in `app.py`. |
| Cannot connect / timeout | Check `DB_DSN`, your internet connection and that your database is running. |
| "No payroll found" on the report | Save attendance and generate payroll for that month first. |
